## §2 — Le critère du verdict

Un verdict répond à une seule question : **la cellule dit-elle encore ce que dit le FR ?**

- `alignée` — le FR a changé de forme (tournure, registre, nombre, construction), pas de
  proposition ; la cellule, traduite sur l'ancien FR, dit donc toujours ce que dit le FR actuel.
  Rien à faire.
- `typographie seule` — le sens est conforme ; le seul écart porte sur la forme des signes (ici,
  des nombres écrits en lettres là où le FR actuel les écrit en chiffres). PR typographique à
  part, pas de retraduction.
- `à retraduire` — le FR a retiré ou ajouté une proposition et la cellule porte l'ancien état :
  clé nommée, crédit owner.

« Proposition » = ce que la phrase affirme et qu'on peut nier séparément (pour le PK 644, trois :
l'ADN de l'auteur du crime porte un trait ; ce trait se retrouve chez l'accusé et chez 10 %
seulement de la population ; on peut affirmer à 90 % de certitude que cet homme est coupable).

Ce que le verdict ne juge pas : la qualité de la traduction en soi, ni celle du FR. Un écart de
lexique ou de registre antérieur à la passe est **signalé** (§4, §5), il n'est pas tranché.

#   - le nombre de cellules traduites des 8 groupes, avant / apres la passe ;
#   - combien de ces cellules sont candidates ;
#   - l'historique FR de chaque groupe (chaque valeur, avec le commit qui l'a ecrite).

def rows_at(rev):

    if raw[:3] == b"\xef\xbb\xbf":
        raw = raw[3:]
    return {r["PK"]: r for r in csv.DictReader(io.StringIO(raw.decode("utf-8"), newline=""))}

cands = list(csv.DictReader(io.open(".tmp/cascade26.csv", encoding="utf-8", newline="")))

date = {l[0]: l[1] for l in log}
pass_sha = next(s for s in order if s.startswith(PASS))
cache = {}
for sha in reversed(order):                      # du plus ancien au plus recent
    try:
        allrows = rows_at(sha)
    except subprocess.CalledProcessError:

    cache[sha] = {pk: allrows[pk] for pk, _ in groups if pk in allrows}
prev, last, fr = {}, {}, {}
for sha in reversed(order):
    for pk, field in groups:
        row = cache.get(sha, {}).get(pk)
        if row is None:
