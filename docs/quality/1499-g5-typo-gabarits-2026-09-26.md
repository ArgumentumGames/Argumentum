## 1. Ce que l'instrument compte — et le piège qu'il évite

**Parser le JSON, jamais greper les octets** (leçon #1485) : le `mustache` et le `css` vivent dans des chaînes JSON, où chaque guillemet est échappé (`\"`). Un motif écrit en clair sur le fichier brut s'arrête au backslash et rend une capture **vide**, qu'on lit comme une déclaration vide.

Et **tout ce qui n'est pas du texte rendu est exclu** :

| compté | exclu, et pourquoi |
|---|---|
| **nœuds de texte** du `mustache` | balises et leurs **attributs** — `class="titre"` est du balisage ; un comptage brut de `"` y voit des milliers de faux défauts |
| chaînes littérales de **`content:`** du `css` (rendues par `::before`/`::after`) | blocs `<style>`/`<script>`, commentaires HTML **et CSS**, expressions `{{…}}`/`{{{…}}}` (ce sont des **données**, injectées depuis le CSV) |

⭐ **Preuve de non-aveuglement** (`--naif` : le même comptage **sans** le dépouillement, sur le **même** arbre) :

```
mode dépouillé (nœuds de texte) :  P=0   A=0
mode BRUT                       :  P=692 A=105
```

L'écart **prouve** que le 0 vient d'une absence réelle dans les nœuds de texte, pas d'un instrument qui ne regarde rien. Le chiffre brut, lui, ne veut rien dire comme compte de défauts : ses 105 « apostrophes fautives » sont des `font-family: 'DINPro'` et des sélecteurs `[class~="2"]`. ⛔ Ne jamais citer le second comme un résultat.

## 2. Les 2 défauts

| gabarit | surface | chaîne mesurée |

| `Cards/Memo/Argumentum_Memo_Back_fr.json` | **`mustache`**, nœud de texte | `<div class="subtitle" …>L'art de ne jamais avoir tort</div>` — **le titre du jeu, sur le dos de la carte mémo** |
| `Cards/Rules/Argumentum_Rules_fr.json` | **`css`**, `content:` | `content: "L'ÉCOLE DES MENTEURS";` — le pied de variante porté par `[class~="2..6"]:before` |

⭐ **La preuve que le gabarit était le traînard, et non la norme** : le même libellé vit sur **trois** surfaces, et les deux autres portaient **déjà** l'apostrophe courbe, parce que le balayage #1562 est passé par les CSV :

```

gabarit Rules, règle `content:`              :  « L'ÉCOLE DES MENTEURS »      ← droite
clé StaticConversions (config)               :  « L'ÉCOLE DES MENTEURS »      ← droite
```

Le #1562 a balayé **les 5 CSV** ; les chaînes écrites en dur dans les gabarits n'étaient pas dans son périmètre. C'est ce trou que ce grain ferme.

## 3. L'écriture — 7 sites, 4 fichiers, en **lockstep**

⚠️ **Aucune de ces chaînes n'est libre** : les deux sont aussi le `sourceText` d'une entrée `StaticConversions` dans `AssetConverterConfig.cs`. Un `Replace` qui ne trouve pas sa clé est un **no-op silencieux** — et le symptôme n'est pas un apostrophe fausse, c'est **les 7 langues qui retombent sur le français**. D'où le lockstep :

| fichier | site | rôle |
|---|---|---|
| `Cards/Memo/Argumentum_Memo_Back_fr.json` | nœud de texte du `mustache` | la chaîne rendue |
| `Cards/Rules/Argumentum_Rules_fr.json` | `content:` du `css` | la chaîne rendue |
| `AssetConverterConfig.cs` | **2** `sourceText` (l. 168, 212) | la clé de conversion |
| `RulesCssStaticConversionTests.cs` | **5** littéraux (tableau des pieds, tuple de dérivation, pic et ses 2 assertions, citation du doc-comment) | les gardes, restatées |

**Pourquoi le test bouge aussi** : ses littéraux **citent** la forme du gabarit. C'est délibéré — le test le dit lui-même (« this Fact fails loudly the day conversions land without updating the test, forcing the measurement to be restated »). Un test qui citerait une forme périmée serait un test qui ne mesure plus rien.

Vérification après écriture :


## 4. Les gardes — et les mutations qui les prouvent

⭐ **Une garde jamais vue rouge est un no-op.** Les deux familles ont été mutées **sur une seule surface**, la config restant dans sa forme neuve :

**A. Memo — le gabarit seul repasse à l'apostrophe droite** (`--filter Memo_Back_Template_Subtitle_Is_Translated…`) :

```
Échoué  (destLang: en) · (destLang: ru) · (destLang: pt)   →  échec : 3, réussite : 0
  « …to contain "L’art de ne jamais avoir tort" because the StaticConversions key
    must match the template subtitle verbatim, otherwise conversion is a no-op
    and {en|ru|pt} falls back to FR (#358) »
```

La garde qui a rougi est **celle qui décrit le vrai risque** (la chute en FR), pas la forme de l'apostrophe. C'est exactement le défaut de #358/#443, et le commentaire du test le rappelle : « Bug 1: apostrophe U+2019 in source vs U+0027 in template -> subtitle stays FR ».

**B. Rules — le `css` seul repasse à l'apostrophe droite** (`--filter RulesCssStaticConversionTests`) :

```
Échoué : 4, réussite : 1
  ✗ Rules_Template_Css_Carries_The_Five_French_Variant_Footers
  ✗ Footer_Conversions_Land_In_All_Non_Fr_Languages_As_Exact_Replacements
  ✗ Static_Conversions_Do_Reach_The_Css_Key_Through_The_Production_Path (×2 InlineData)
  ✓ Config_Footer_Translations_Are_Derived_From_The_Rules_Csv_Cover_Rows
```

Le seul test resté **vert** est celui qui **dérive du CSV** : il ne lit pas la forme du gabarit, et c'est correct — sa mutation à lui est la dérive du CSV, pas celle du gabarit. Un 5/5 rouge aurait signalé une garde qui rougit pour de mauvaises raisons.

**Restauration** : les deux gabarits ont été rétablis depuis une copie **hors dépôt**, à l'octet (sha256 comparés avant/après) — jamais par `git checkout --`.

## 6. Limites

- Les 11 gabarits sont **tous `_fr`** : les autres langues n'ont pas de gabarit propre, elles sont produites par `StaticConversions` au-dessus du gabarit fr. Le périmètre mesuré est donc le bon — mais il signifie que **la typographie non-fr des textes en dur dépend des `destText` de la config**, non mesurés ici (le `904-verifie-BC-independant.py` couvre les CSV, canal A : 0 résiduel).
- La norme appliquée est celle du dry-run #1562 (`TARGET` : `fr` → courbe, `en` → droite, `"` interdit partout), comptée **intra-mot** comme `count_wrong`. ⚠️ Le vérificateur #994 exclut `fr` de son canal A (« volet A fermé ») ; les deux lectures ne se contredisent pas mais ne mesurent pas la même chose — c'est le dry-run qui porte la norme.
- L'instrument ne juge que **deux canaux** (guillemet droit, apostrophe intra-mot). Une typographie fautive d'une autre nature (espace insécable, tiret) **n'est pas vue**.
- ⛔ **Aucune régénération** n'a été lancée : le correctif de gabarit se vérifie en **Debug** (chemin local), un rendu **Release lit le gabarit sur `raw…/master/`** et ne verrait pas la correction avant merge (#1225/#1228).
