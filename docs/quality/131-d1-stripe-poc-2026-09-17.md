## §3 — Ce que Stripe Products + Payment Links couvre, et ce qu'il ne couvre pas

| Fonction | OpenStore aujourd'hui | Stripe Products + Payment Links |
|---|---|---|
| Catalogue produit/prix | dans DNN (`PRD`/`PRDLANG`) | hébergé Stripe (Products, Prices) |
| Checkout | page DNN + plugin Stripe | **page Stripe hébergée** (Payment Link) — SCA/3DS, moyens de paiement, reçus gérés par Stripe |
| Panier multi-articles | oui (module) | **non** : Payment Link = achat direct d'un produit/variante (panier Stripe possible côté Checkout API, hors Payment Link) |
| Comptes clients DNN | 111 `CLIENT` | **non** : identité portée par Stripe (pas de compte dans le site) |
| Historique commandes dans le site | 124 `ORDER` | **non** : historique dans le Dashboard Stripe |
| Livraison / transporteur | OS_Chronopost2 intégré | à recadrer (Stripe Shipping Rates ou process manuel) — **fonctionnalité perdue** |
| Taxes | `TAX` + réglages module | **Stripe Tax** (option payante) ou paramétrage manuel |
| Pages produit multilingues | `PRDLANG` (fr/en) | partiel (Checkout localisé par langue) |
| Intégration menu/UX du site | intégrée (`/Acheter-le-jeu`) | **page statique pointant vers les liens Stripe** (UX boutique intégrée perdue) |
