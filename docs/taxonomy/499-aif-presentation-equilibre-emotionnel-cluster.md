## 2. 🔑 Décomposition I/RA/CA — PREMIER cas rebut/CA-node (PK 340)

### 2.1 PK 340 Appel aux conséquences = rebut / CA-node (natif AIF, cas paradigmatique)

**340 Appel aux conséquences** — *« Vous fondez votre argumentation sur les conséquences d'une idée plutôt que
sur sa justesse »* = **argumentum ad consequentiam**.

**Décomposition AIF** :
- Le défenseur d'une vertu (53/54) tient légitimement **Argument from Consequences** (scheme Walton natif) :
  les conséquences réelles d'une idée peuvent être une raison légitime d'agir/préférer.
- La fallacy 340 **détourne** ce scheme : au lieu d'évaluer si P est **vraie/juste**, l'argueur fonde son
  rejet de P sur les **conséquences** (indésirables) de P. La conclusion tirée est *« P doit être rejeté / non-P »*.
- Cette conclusion *non-P* **conflit** avec la conclusion ciblée *P*. L'attaque porte sur la **conclusion** (un
  I-node conclusion est contredit), médiée par un **CA-node** (Conflict Application) qui lie le
  consequence-argument au target.
- → **`rebut` / `CA-node`**. C'est **le premier cas rebut/CA-node propre** du chantier (5 familles / 31 instances
  sans rebut avant ce cluster).

**Discriminateur rebut vs undercut vs undermine (raffine back-fill plan #744)** :
- L'argueur ne dit pas « la prémisse de P est fausse » (ce serait undermine/I).
- L'argueur ne dit pas « l'inférence de P est mauvaise » (ce serait undercut/RA).
- L'argueur **avance une contre-conclusion** (non-P, via l'évaluation des conséquences) qui **conflit** avec P
  au niveau de la conclusion. → rebut/CA.

**Honnêteté #677** : rebut + CA-node + Argument from Consequences = **tous natifs AIF/Walton** (Argument from
Consequences est un scheme Walton listé ; CA-node est un nœud AIF natif). 0 fabrication. Le verdict reflète la
structure réelle de la fallacy, pas un forçage pour « combler le rebut ».
