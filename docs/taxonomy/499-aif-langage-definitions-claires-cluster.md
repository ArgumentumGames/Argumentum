## 2. Décomposition I/RA/CA — attack-type + attacked-node (Option A)

### 2.1 🔑 Résolution du borderline 804 (raffine back-fill plan #744 §2a)

Le back-fill plan #744 classait **804 Acception arbitraire** en *borderline* (défaut conservateur undercut/RA).
Ce cluster le résout per-case en lisant le mécanisme : *« Vous inventez une définition sur mesure pour vos termes,
sans respecter leur sens commun »*.

**Triade 800 / 804 / 826** (les 3 fallacies de définition, Abus de langage 5.1.x) :
- **800 Acception vague** (*« termes imprécis pour rester évasif »*) : le terme n'a pas de définition déterminée →
  l'inférence classification (terme→classe) est indéterminée → **undercut / RA-node** (le scheme Verbal
  Classification ne peut s'appliquer, la règle est floue).
- **804 Acception arbitraire** (*« inventez une définition sur mesure »*) : une définition est **fabriquée** pour
  forcer la classification voulue → la **prémisse définitionnelle** (I-node) est fausse par rapport au sens
  commun → **undermine / I-node**. Le contenu de la prémisse est inventé, pas l'inférence qui est cassée.
- **826 Définition incohérente** (*« définitions contradictoires »*) : les définitions données se contredisent →
  l'inférence est incohérente (règle inconsistante) → **undercut / RA-node**.

**Verdict 804 raffiné : `undermine / I-node` (clean, plus borderline).** Justification : la fallacy asserte une
définition fabriquée (prémisse I-node fausse), distincte de 800 (vagueness → inference indéterminée) et 826
(contradiction → inference inconsistante). Les 3 fallacies de définition tombent sous 3 attack-shapes AIF
distinctes — c'est exactement la granularité que la décomposition I/RA/CA sert à capturer.

**Impact sur back-fill plan #744** : §2a table, ligne 804 — passer de *« BORDERLINE, défaut conservateur undercut »*
à *« undermine / I-node (clean) »*. Les **4 nœuds opposant 804** (137, 139, 140, + vérifier) deviennent undermine/I.
Distribution back-fill mise à jour : ~9-13 nœuds undermine/I (889 + 804), reste undercut/RA, toujours 0 rebut.

### 2.2 Dérivation par leaf

**5.1.1.1 pk 137 — Langage précis** (Verbal Classification : terme précis → classe déterminée)
- 855 Équivoque (*« exploitez les différents sens d'un même mot »*) : le terme a plusieurs sens → l'inférence
  terme→classe est ambiguë (règle non-déterminée) → **undercut / RA-node**.
- 804 Acception arbitraire → **undermine / I-node** (§2.1).

**5.1.1.2 pk 138 — Langage concis** (Verbal classification : expression concise → clarté)
- 667 Imprécision (*« données imprécises → conclusions incertaines »*) : prémisse **imprécise** (déficit de
  qualité, pas assertion fausse) → l'inférence est affaiblie → **undercut / RA-node** (borderline mine écarté :
  l'imprécision n'est pas une assertion connue-fausse, c'est un défaut de granularité).
- 1345 Complication exagérée (*« complexifiez volontairement le débat »*) : la complexification empêche
  l'inférence classification de se résoudre → **undercut / RA-node**.

**5.1.2 pk 139 — Définition conforme** (Verbal classification : définition = sens commun)
- 804 Acception arbitraire → **undermine / I-node** (§2.1, définition fabriquée).
- 800 Acception vague → **undercut / RA-node** (§2.1, vagueness).

**5.1.2.1 pk 140 — Terminologie technique** (Expert Opinion : terme technique défini par l'expertise)
- 804 Acception arbitraire → **undermine / I-node** (§2.1).
- 855 Équivoque → **undercut / RA-node** (§2.1).

**5.1.3 pk 141 — Définition cohérente** (Verbal classification : définition non-contradictoire)
- 826 Définition incohérente → **undercut / RA-node** (§2.1, contradiction inference).
- 777 Inconsistance (*« affirmations qui se contredisent »*) : self-contradiction interne → l'inférence repose
  sur des prémisses mutuellement exclusives → **undercut / RA-node**. (Pas un rebut : pas de contre-conclusion
  indépendante avancée, mais une incohérence interne qui défait la règle.)
