## 2. Décomposition I/RA/CA — attack-type + attacked-node (Option A)

### 2.1 🔑 Test du discriminateur undermine raffiné (PR-4 §3.1 / PR-5 §2.1) sur 953 Attention sélective

Le discriminateur raffiné réserve `undermine`/I-node à l'**assertion d'une prémisse fabriquée/fausse** (889
Mensonge, 804 Acception arbitraire), par opposition aux tool-misuse, credibility-attacks et **sélections
biaisées** (`undercut`/RA). PR-5 a confirmé ce discriminateur sur le cas statistique 596 Échantillon biaisé.
PR-7 le teste sur le cas discursif **953 Attention sélective** (cherry-picking) :

**953 Attention sélective** — *« Vous ne présentez que les faits qui soutiennent votre thèse, en occultant ceux
qui la contredisent »*.
- Les faits présentés peuvent être **tous factuellement exacts** — c'est leur **sélection** (non-représentative,
  occultiée des contre-faits) qui est défectueuse, **pas leur vérité**.
- L'inférence (les faits sélectionnés → la thèse) ne tient pas : la règle « ces faits représentent l'ensemble
  du picture » est invalide pour cette sélection.
- → **undercut / RA-node**, **PAS undermine**. Logique **identique à 596** (PR-5) : sélection biaisée =
  inference cassée, pas prémisse fabriquée.

**Confirmation double du discriminateur** (596 statistique + 953 discursif) : `undermine` reste réservé aux
**prémisses fabriquées/fausses**. Une sélection biaisée (596, 953), une imprécision (667), un outil mal utilisé
(644), un cadre distordu (1242) = tous `undercut`/RA. Le défaut porte sur l'**inférence**, pas sur la **vérité
de la prémisse**. Renforce encore la prévisibilité du back-fill plan #744 §2a.

### 2.2 Dérivation par leaf

**1.1.1 pk 3 — Argument réel** (Argument from Sign : les éléments invoqués sont des signes contrôlables de la conclusion)
- 3 Argument vide (*« affirmations qui n'apportent rien à la construction d'un argument convaincant »*) :
  l'argument n'est **pas étayé** — il manque les signes/preuves qui supporteraient l'inférence signe→conclusion →
  **undercut / RA-node**. (Pas un undermine : l'arguer n'asserte pas une prémisse fausse, il n'en fournit
  simplement pas. Pas un rebut : pas de contre-conclusion, un déficit de support.)
- 1297 Preuve par assertion (*« répétez votre point de vue avec insistance au lieu de fournir de véritables
  preuves »*) : la répétition **remplace** la preuve — l'inférence n'a aucun support factuel →
  **undercut / RA-node**. La répétition n'est pas une prémisse fabriquée (rien d'asserté de faux), juste
  l'absence de signe vérifiable.

**1.1.2 pk 6 — Preuves tangibles** (Argument from Sign : les preuves sont tangibles et probantes)
- 3 Argument vide → **undercut / RA-node** (§3, déficit de support).
- 1297 Preuve par assertion → **undercut / RA-node** (§3, répétition-à-la-place-de-preuve).

**1.1.3 pk 11 — Raisonner sans biais** (Argument from Bias : le raisonnement tient compte des faits pertinents sans sélection biaisée)
- 953 Attention sélective → **undercut / RA-node** (§2.1, cherry-picking = sélection biaisée = inference cassée).
- 1242 Biais théoriques (*« raisonnez dans un cadre déformé par une application trop rigide de concepts
  théoriques »*) : le **cadre théorique** appliqué est trop rigide, ce qui **distord** le raisonnement —
  l'inférence (prémisses → conclusion) passe par un filtre déformant → **undercut / RA-node**. Pas un undermine
  (pas de prémisse fabriquée), pas un rebut (pas de contre-conclusion) : un biais de traitement de l'inférence.

## 3. 🔑 Validation du 2e scheme dominant Argument from Sign (26 nœuds pleine échelle)

PR-7 couvre **Argument from Sign** (pks 3, 6) pour la première fois dans le chantier I/RA/CA. C'est le scheme
**2e plus représenté** à pleine échelle (26 nœuds / 222 = ~12% de la taxonomie, après Rule 50). Sa validation
sur le cas paradigmatique {Argument vide, Preuve par assertion} (les archétypes de l'argument non étayé)
confirme :

- **Argument from Sign → défaut `undercut` / `RA-node`**. Une vertu « signe vérifiable / preuve tangible » est
  résistée par l'argument vide (3) et la preuve par assertion (1297), qui **défont le Sign Application node**
  (aucun signe observable ne supporte l'inférence vers la conclusion). Logique identique au défaut général.
- **Pas d'override** attendu pour les nœuds Sign : le scheme Sign ne génère pas de prémisse fabriquée (pas
  d'undermine — les fallacies opposées sont des déficits de support, pas des assertions fausses) ni de
  contre-conclusion (pas de rebut). Le back-fill plan peut traiter les 26 nœuds Sign en pur défaut mécanique.

**Impact back-fill plan #744** : confirme (avec Rule en PR-5) que **le scheme n'est PAS un axe d'override** —
l'override vient du **mécanisme de la fallacy opposée** (889/804 → mine, 340 → rebut), pas du scheme de la
vertu. Sign comme Rule = `undercut`/`RA-node` sauf override par la fallacy opposée. Renforce la simplicité du
script apply.
