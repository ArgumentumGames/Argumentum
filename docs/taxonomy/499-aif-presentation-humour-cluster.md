## 2. Décomposition I/RA/CA — attack-type + attacked-node (Option A)

### 2.1 🔑 Document 1398 Attaque personnelle = négation explicite du rebuttal (renforce rebut-rarity)

PR-6 a révélé le premier rebut/CA-node (PK 340). Le back-fill plan #750 encode le set rebut {340} avec la
leçon : les overrides rebut viennent de l'analyse per-case du mécanisme AIF. PR-9 documente le **contre-exemple
parfait** — une fallacy relationnelle qui ressemble à un rebut mais qui ne l'est PAS :

**1398 Attaque personnelle** — *« Au lieu de réfuter les arguments, vous attaquez directement la personne qui
les présente »*.
- La taxonomie elle-même la définit par **« au lieu de réfuter »** = **négation explicite du rebuttal**.
- L'attaque ne présente pas une contre-conclusion soutenant le contraire de P ; elle **détourne** l'attention de
  l'argument vers la personne → c'est une attaque de **crédibilité/engagement** (ad hominem), pas une réfutation
  du contenu.
- → **undercut / RA-node**, **explicitement PAS rebut**.

**Confirmation load-bearing** : la définition taxonomy *« au lieu de réfuter »* est la **preuve native** que
rebut est structurellement rare — les fallacies relationnelles (ad hominem, etc.) sont des détournements
(undercut/RA), pas des réfutations (rebut/CA). Le set rebut {340} reste localisé au mécanisme
contre-conclusion.

PR-9 couvre **Argument from Values** (pks 43/44/45/47) pour la première fois dans le chantier I/RA/CA. C'est le
**dernier scheme majeur non couvert** (~6-8 nœuds pleine échelle : Humour subfamily 43/44/45/47 + Universalisme
168 + Recherche de compromis 198). Sa validation sur le cas paradigmatique {219 Humour, 1398 Attaque
personnelle, 1174 Biais culturels} confirme :

  par l'humour-persuasion-sans-faits (219), l'ad hominem (1398) et le biais culturel (1174), qui **défont le
  Values Application node** (l'humour ne sert plus une valeur épistémique mais la persuasion/le détournement).
- **Pas d'override** attendu pour les nœuds Values : le scheme ne génère pas de prémisse fabriquée (pas
  d'undermine) ni de contre-conclusion (pas de rebut — 1398 le nie explicitement). Le back-fill plan peut
  traiter les nœuds Values en pur défaut mécanique.

**Impact back-fill plan #750** : confirme (avec Rule PR-5, Sign PR-7, Position to Know PR-8) que **le scheme
n'est PAS un axe d'override**. Values comme Rule/Sign/PtK = `undercut`/`RA-node` sauf override par la fallacy
opposée (889/804 → mine, 340 → rebut). **Top-4 schemes désormais validés** : Rule 50 + Sign 26 + Position to
Know 8 + Values ~6-8 = ~90 nœuds / **~40% de la taxonomy** en pur défaut mécanique.
