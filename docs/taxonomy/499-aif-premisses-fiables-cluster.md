## 2. Décomposition I/RA/CA — attack-type + attacked-node (Option A)

### 2.1 🔑 Test de la classification credibility-attack de 942 Fausse attribution (déjà établie PR-2 + #744)

Le back-fill plan #744 §2a a **explicitement exclu** 942 Fausse attribution du set undermine :
> *« 942 Fausse attribution (source = credibility, cf. PR-2) → undercut/RA, NOT undermine »*.

PR-8 réexamine 942 dans son contexte Position to Know (leaf 13) pour **confirmer et documenter la distinction** :

**942 Fausse attribution** — *« vous donnez du poids à votre argument en citant une source fausse, mal identifiée,
incompétente ou inventée »*.
- La **source** est fausse/inventée. Mais la **fabrication** ne porte pas sur la *proposition de fond P* — elle
  porte sur la **qualification épistémique de la source** (« cette source est compétente/identifiable »).
- L'arguer n'asserte pas « P est vraie » comme prémisse fabriquée (889-style) ; il asserte « **cette source
  sait que P** » et dérive P de là. La prémisse falsifiée est *la fiabilité de la source*, pas P elle-même.
- → l'attaque défait l'**inférence** Position-to-Know (source fiable → P), **pas la conclusion P directement**.
- → **undercut / RA-node**, **PAS undermine**.

**Confirmation** : 942 est un **credibility-attack** (comme établi PR-2). Le discriminateur tient : `undermine`/I
est réservé aux **prémisses de fond fabriquées/fausses** (889, 804) ; la falsification d'une *qualification de
source* (942) défait l'inférence, pas la prémisse de fond. Renforce le back-fill plan #744 §2a (942 reste
undercut/RA).

### 2.2 Dérivation par leaf

**1.2.1 pk 13 — Sources crédibles** (Argument from Position to Know : la source est en position fiable de connaître)
- 71 Argument d'autorité (*« croyez une affirmation vraie uniquement parce qu'une autorité la soutient, sans
  examiner les faits »*) : l'autorité est invoquée **au lieu** des faits → l'inférence (autorité dit P → P) n'est
  pas supportée par un examen factuel. L'autorité peut exister réellement (pas de prémisse fabriquée), mais la
  **Position to Know Application** est abusive (l'autorité n'est pas une position-to-know légitime *pour cette
  conclusion*, ou la conclusion déborde son expertise) → **undercut / RA-node**. **Cas paradigmatique du Position
  to Know breakdown** (Appel à l'autorité = archétype de l'expertise mal invoquée).
- 942 Fausse attribution → **undercut / RA-node** (§2.1, credibility-attack).

**1.2.2 pk 25 — Sources indépendantes** (Argument from Position to Know : les sources multiples/indépendantes convergent)
- 953 Attention sélective → **undercut / RA-node** (PR-7 §2.1, cherry-picking = sélection biaisée = inference
  cassée).
- 596 Échantillon biaisé → **undercut / RA-node** (PR-5 §2.1, sélection biaisée = inference sample→population
  cassée).

**1.2.3 pk 26 — Sources impartiales** (Argument from Bias : la source est impartiale, sans intérêt personnel)
- 953 Attention sélective → **undercut / RA-node** (PR-7 §2.1).
- 1024 Biais naturels (*« vos arguments reflètent les limites et les réflexes liés à la perspective humaine »*) :
  les **heuristiques cognitives naturelles** distordent le raisonnement → l'inférence est biaisée par des réflexes
  humains → **undercut / RA-node**. Comme 1242 (PR-7, cadre théorique distordu), le défaut porte sur le
  **traitement de l'inférence** (biais cognitif), pas sur la vérité d'une prémisse (pas mine) ni sur une
  contre-conclusion (pas rebut).

le **3e scheme majeur restant** (8 nœuds / 222 = ~4% de la taxonomie). Sa validation sur le cas paradigmatique
{Argument d'autorité 71, Fausse attribution 942} (les archétypes de l'expertise mal invoquée) confirme :

- **Argument from Position to Know → défaut `undercut` / `RA-node`**. Une vertu « source en position fiable de
  connaître / sources indépendantes convergente » est résistée par l'autorité invoquée hors-sujet (71) et la
  source falsifiée (942), qui **défont le Position to Know Application node** (la source n'est pas réellement en
  position de connaître ce qu'elle affirme).

  fabriquée (pas d'undermine — la falsification de *qualification de source* 942 défait l'inférence, pas la
  prémisse de fond) ni de contre-conclusion (pas de rebut). Le back-fill plan peut traiter les 8 nœuds Position
  to Know en pur défaut mécanique.

**Impact back-fill plan #744** : confirme (avec Rule PR-5, Sign PR-7) que **le scheme n'est PAS un axe
d'override**. Position to Know comme Rule/Sign = `undercut`/`RA-node` sauf override par la fallacy opposée
(889/804 → mine, 340 → rebut). **Top-3 schemes désormais validés** : Rule 50 + Sign 26 + Position to Know 8 = 84
nœuds / **~38% de la taxonomy** en pur défaut mécanique.
