## По языкам — полный комплект, 8 раз

Каждый язык получает **полный** комплект: **10 PDF-документов** (опубликованные имена — в
[производной таблице #2234](135-downloads-assets-table.md); 10 основ × 8 языков = 80 активов) плюс **два
пакета**, собираемых при теге инструментом [`tools/135-build-download-zips.py`](../../tools/135-build-download-zips.py)
и прикрепляемых к финальному релизу:

- **Цифровые карты** — `Argumentum_Cards_PNG_ru.zip`: **175** карт в PNG, пересобранных из того же дерева
  генерации, что и релиз (ныне публикуемые PNG существуют только на французском и содержат 157 карт);
- **Карты памяти (mind maps)** — `Argumentum_MindMaps_ru.zip`: SVG софизмов **и** добродетелей данного
  языка из репозитория (`Cards/Fallacies/Mindmaps/ru/`) плюс ссылка на страницу сайта с их показом.
