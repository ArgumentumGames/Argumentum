## Note d'instrument — les deux faux positifs que la passe naïve produisait

Une première passe sans exclusions comptait **2 `"` (Memo Face)** et **47+105 / 69+95 `'`+`"` (templates
mindmap racine)**. Les deux familles étaient du **code**, pas du texte joueur :

1. `{{#ifCond Famille "==" text_fr}}` (Memo Face) — l'opérateur du helper Handlebars, **syntaxe de gabarit**,
   disparaît au rendu ;
2. les templates mindmap racine portent leurs règles CSS et leur JS **inline** dans `<style>`/`<script>` —
   `font-family: 'DINPro'`, `// Remove the 'active' class` — comptés comme « texte » par un extracteur
   qui ne distingue pas les blocs de code.

L'instrument livré exclut les blocs script/style et les jetons `{{…}}` avant comptage. Sans ces exclusions,
l'inventaire aurait peint une surface de défaut fausse de ~300 marques — même famille que « un 0 n'est une
absence que si l'instrument pouvait voir un 1 », inversé : ici l'instrument voyait des 1 qui n'existaient pas.

## Ce que cet inventaire n'établit pas

- Il ne corrige rien : counts + exemples pour décision ai-01 (0 écriture).
- L'extracteur HTML est tolérant (regex), pas un parseur : un contenu généré par JS au runtime n'est pas vu.
- Les wrappers `<lang>/` des mindmaps sont GÉNÉRÉS (texte hérité du CSV, déjà balayé par #1562) : non recomptés.
- `en` garde l'apostrophe droite (#1562) : ses comptes sont informatifs, pas des défauts.
- Les guillemets droits `"` en texte français devraient être « » (norme mesurée #1562) — à juger sur les exemples.
- regles.md exclu (⛔ accord co-auteur requis, dispatch) ; DNNPlatform/ framework tiers non balayé.

import json, re, csv, glob, collections

TAG_RE = re.compile(r">([^<>]+)<")
ATTR_RE = re.compile(r"""(?:alt|title|aria-label|placeholder)\s*=\s*["']([^"']*)["']""", re.IGNORECASE)
CONTENT_RE = re.compile(r"""content\s*:\s*["']([^"']*)["']""")
SCRIPT_STYLE_RE = re.compile(r"<(script|style)\b.*?</\1>", re.IGNORECASE | re.DOTALL)
MUSTACHE_TOKEN_RE = re.compile(r"\{\{.*?\}\}", re.DOTALL)

def harvest_html(text):
    """Texte visible d'un fragment HTML : noeuds textuels + attributs visibles.
    Exclut le code (blocs script/style) et la syntaxe de gabarit (jetons {{...}},
    ex. l'opérateur \"==\" de ifCond) — invibles au joueur, comptés comme faux
    positifs par la première version de l'instrument."""
    text = SCRIPT_STYLE_RE.sub("", text)
    text = MUSTACHE_TOKEN_RE.sub("", text)
    parts = [m.group(1) for m in TAG_RE.finditer(text)]
    parts += [m.group(1) for m in ATTR_RE.finditer(text)]
    return [p for p in parts if p.strip()]

def harvest_css(text):
    return [m.group(1) for m in CONTENT_RE.finditer(text)]

def count_straights(parts):
    apos = sum(p.count("'") for p in parts)
    quot = sum(p.count('"') for p in parts)
    return apos, quot

def exemplars(parts, n=3):
    ex = [p.strip()[:90] for p in parts if "'" in p or '"' in p]
    return ex[:n]
