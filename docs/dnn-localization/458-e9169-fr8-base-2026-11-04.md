Script `fix-e9169-fr8.ps1` (scratchpad), deux passes sur le **même** chemin de code :
`-Apply` absent = essai à blanc, présent = commit.

  doit porter encore *exactement* l'ancienne valeur mesurée → **8/8 confirmées**.
- **UPDATE** par `ValueId`, `EntityId = 9169`, et `NOT EXISTS` sur la dimension (anti-rejeu

- **Rendus (2/8)** — `MessageRecaptchaMissing` et `MessageSendError` : chaque culture sert
  **sa** langue ; sur `fr`, la page sert le texte du registre fr (« Veuillez remplir tous
  les champs… », « Une erreur inattendue s'est produite… ») là où la base portait l'anglais.
- **Dormants (6/8)** — `MessageContainsRecaptcha`, `MessageDefaultMailChimpKey`,
  `MessageEnableMailchimp`, `MessageMailFromError`, `MessageMailOwnerError`,
  `MessageRecaptchaWarning` : absents **dans les 8 langues sur les 8 cultures**, avant comme
  après (leurs fragments anglais comptaient déjà 0). Ce sont des avertissements
  conditionnels et **leurs déclencheurs n'existent pas sur cette instance** : la page ne
  contient ni champ reCAPTCHA ni mention Mailchimp (comptes 0). ⚠️ **Un zéro ici n'est pas
  une preuve de non-régression** — c'est une absence structurelle ; la preuve pour ces 6
  est au §4, pas sur la page. Leur base porte désormais le français, donc si une condition
  se déclenche un jour, c'est le texte français qui s'affichera.
- **Les 7 autres cultures sont inchangées par construction, et c'est mesuré** : chacun des
  8 attributs porte **1 rangée dim-0 + 7 rangées dimensionnées** (requête du 04/11 :
  `dim=7 total=8` par attribut), donc elles ne lisent jamais la base ; les compteurs
  globaux (209/168) sont identiques avant et après, et la matrice ne montre aucune
  substitution croisée.

## 6. Instruments — pièges de ce grain

- La table d'attributs est **`TsDynDataAttribute.StaticName`** (pas `AttributeName`, pas
  `TsDynAttribute`) — deux essais perdus avant la bonne colonne.
- `[void]$c.Parameters.Add(...).Value = x` est une **erreur de parse** en PowerShell
  (affectation d'un membre sur un cast `[void]`) ; et `$pid` est une variable automatique
  **en lecture seule**. Deux statements, nom de variable dédié.
- **Un booléen de présence ne mesure pas** : la première matrice rendait « chaque culture
  contient les 8 langues ». Remplacée par une **matrice de comptes 8×8 avec contrôle
  négatif** — seule forme qui prouve que l'instrument sait distinguer. Même famille que
  « un `0` n'est une absence que si l'instrument pouvait voir un `1` ».
- **Borne du magasin** : la page d'accueil mélange les surfaces ; le bloc contact est
  `data-accordion-child="10182"` (5 149 o, `Envoyer`/`Sujet`/`msgIncomplete` y sont, ce qui
  valide l'extraction). Les avertissements dormants n'y sont pas, quel que soit le geste.
