## 5. Sûreté — les gardes, dans l'ordre

1. **pré-état asserté** : 0 rangée de dimension sur l'app 35 (refus sinon) ;
2. **contrôle d'identité** (garde nouvelle par rapport à l'app 59) : la colonne `fr` du pivot doit
   être **octet pour octet** la valeur base en DB pour chacun des 15 couples (guid, champ) — 15/15 OK.
   C'est ce qui garantit que le GUID du pivot désigne bien l'entité décrite ;
3. garde `valeur == fr` : une « traduction » identique au français est refusée ;
4. dry-run vert : 105/105 résolues, **0 problème**, refus si le jeu n'est pas exactement 105 ;
5. transaction unique, **relecture AVANT commit** (105/105 octet-identiques), `ROLLBACK` sur écart ;
6. identifiants insérés consignés (`rollback-app35.json`, scratchpad de session, **jamais committé**) —
   rollback = `DELETE FROM TsDynDataValueDimension WHERE ValueId IN (…)` puis
   `DELETE FROM TsDynDataValue WHERE ValueId IN (…)`.

Recycle app-domain : mtime de `DNNPlatform/web.config` touchée, **sha256 inchangé**. Traductions
servies au premier sondage après les ~40 s de recycle.
