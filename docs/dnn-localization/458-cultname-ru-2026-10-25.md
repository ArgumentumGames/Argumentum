### La casse : écart assumé avec la formulation de l'arbitrage

L'arbitrage 5 et le constat #1974 §6 formulent « Русский (Россия) » (majuscule). La valeur
écrite est **`русский (Россия)`** (minuscule) car :

1. c'est le `NativeName` .NET **Framework 4.8** calculé sur la machine qui sert le site (même
   BCL que le serveur) ;
2. la convention **mesurée** de la table est la minuscule initiale sur 5/8 rangées
   (`français`, `español`… ; pt-BR majuscule = écriture du pack de langue, pas une convention
   BCL ; en-US est un nom propre, majuscule dans le NativeName lui-même).

La formulation de l'arbitrage décrivait la valeur attendue, pas un contrat d'octets (contraire
au hex épinglé zh-CN de #1974). Si ai-01 préfère la forme majuscule : `UPDATE` d'une rangée.
