le filtre, seul, ne l'aurait pas fait. **L'outil n'a pas été modifié dans cette PR** (élargir `DEMO` est
une décision à part, avec ses propres contrôles inverses : un motif trop large mangerait du contenu réel).

## 5. Preuves d'intégrité du registre

C'est un fichier de données suivi, à encodage et fins de ligne sensibles ; le geste n'est admis que si
l'on prouve que **seules** les cellules visées ont bougé.

| Contrôle | Mesure |
| --- | --- |
| L'écrivain reproduit l'original | `writer(parse(original)) == original` **octet pour octet** (vrai) |
| Cellules modifiées | **42**, toutes dans les colonnes de langue ; **aucune** colonne non-linguistique touchée |
| `\r\n` (CRLF **dans** les cellules) | **216 avant / 216 après** |
| LF seuls (séparateurs d'enregistrement) | **4 651 avant / 4 651 après** |
| BOM | absent avant, absent après |
| `git diff --numstat` | **`6 6`** — 6 lignes physiques, une par rangée changée |
| Entités doublement échappées dans les cellules neuves | **0** (`&amp;` / `&quot;` : aucun) |

Le premier contrôle est celui qui rend les autres concluants : puisque l'écrivain reproduit l'original à
l'octet près, tout écart d'octet dans le fichier produit est **attribuable** aux cellules changées.
